Sistema desenvolvido para controle das operações de uma copiadora, integrando **backend em Spring Boot** e **frontend em React/Vite**.

Principais características:

* Interface desenvolvida com React e Vite
* Integração entre frontend e backend
* Persistência de dados utilizando SQLite
* Automação do build do frontend através do Maven
* Scripts para execução da aplicação
* Preparação para distribuição da aplicação
* Empacotamento utilizando jpackage
